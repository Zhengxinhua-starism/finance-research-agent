# 数据覆盖度盘点

## 这份文档解决什么问题

在此之前，这个项目的数据层是**按接口组织**的：`get_income_history` 的语义是
"包装新浪利润表接口"，而不是"提供成本结构分析所需的数据"。

后果是数据覆盖范围等于"当初恰好想到的那几个接口"，没有任何地方定义过
"回答一个归因类问题究竟需要哪些数据"。于是缺口只能靠个案发现——
拿一个具体问题去和别的产品对比，发现漏了什么，补一个工具，
下次换个问题再暴露新的。这是打地鼠，不是工程。

本文档把"分析维度 → 数据需求 → 覆盖状态 → 数据源"显式列出来，
它同时是三样东西：

1. **能力边界声明**：明确哪些问题答得了、哪些答不了、为什么；
2. **新增工具的检查表**：接一个新数据源前，先在这里定位它填补哪个维度；
3. **缺口的待办清单**：状态非 ✅ 的每一行都是一个待办。

> 盘点日期：2026-08-13　|　样本标的：002594（比亚迪）　|　数据源：AKShare 1.18.85
> 表中的实测值都是当天真实拉取的，不是示例。
>
> **2026-08-13 更新**：P0 与 P1 已完成。新增两个工具
> （`get_segment_breakdown`、`get_operating_efficiency`），
> 工具总数 8 → 10；补齐了期间费用、利润构成、有息负债、资本开支等字段。
> 十个维度中完全为空的从 3 个降到 1 个（只剩同业对比）。
> 各维度状态已在下方更新，待办表见第四节。

## 状态图例

| 标记 | 含义 | 处置方式 |
|------|------|---------|
| ✅ | 已覆盖，数据正常送达 LLM | — |
| 🟡 | **已抓取但未输出**：字段解析进了模型对象，但 `to_display()` 没吐出来 | 改一行输出即可 |
| 🔴 | **别名失配**：代码以为抓到了，实际恒为 `None`，且不报错 | 修别名，属于 F-001 同类 bug |
| ⬜ | **可覆盖未接**：数据源存在且免费，只是没接 | 需要新增工具或扩展现有工具 |
| ⛔ | **数据源不可得**：AKShare 无对应接口 | 写进能力边界，研报中如实声明 |

🟡 和 🔴 是最危险的两类：它们不报错，只是让研报里出现"数据缺失，无法判断"，
而数据其实就在手里。

## 一、按分析维度的覆盖状态

### 1. 盈利能力

### 3. 分部结构（业务/地区拆解）

| 数据项 | 状态 | 说明 |
|--------|------|------|

## 三、能力边界（明确答不了的问题）

以下内容**不是待办**，是需要在研报中如实声明的固有限制：

| 答不了什么 | 原因 | 研报应如何处理 |
|-----------|------|---------------|
| 销量、单价、单车利润 | AKShare 无个股产销接口 | 归因停在成本/收入增速对比，声明无法做量价拆解 |
| 折旧摊销明细 | 在年报附注，主表接口不返回 | 不提供单位折旧分析 |
| 研发资本化流量与资本化率 | 同上（只有"开发支出"存量） | 只报研发费用，不报研发投入总额 |
| 真实披露日期 | 需爬交易所公告（F-008） | 用法定截止日保守估算，宁可误拦 |
| 管理层战略表述、业绩指引 | 年报 MD&A 正文，无结构化接口 | 不做前瞻性判断（本就在禁止范围内） |

## 五、维护规则

1. **新增任何工具前，先在本文档定位它填补哪个维度。**
   如果找不到对应维度，说明要么维度清单不完整（先补清单），
   要么这个工具是个案驱动的补丁（应当质疑）。

2. **接入一个接口后，检查它返回的字段是否全部送达 LLM。**
   本次盘点里 🟡 和 🔴 两类共 4 处，全部是"抓到了但没用上"——
   这类问题不报错、不抛异常，只表现为研报里的"数据缺失"，极难发现。
   检查方法：对比模型对象的字段列表与 `to_display()` 的输出键。

3. **状态从 ⬜ 变 ✅ 时，同步更新对应维度的行，并在 `eval/failure_log.md`
   记录变更。** 本文档必须反映真实状态，一旦失真就失去检查表的作用。

4. **⛔ 行不要反复讨论。** 那是数据源的边界，不是实现问题。
   要突破只能换数据源，那是另一个量级的决策。

## 六、这份盘点自身的局限

- 只覆盖了 A 股基本面数据，未盘点港股/美股、宏观、行业景气度等；
- 样本只用了 002594 一只标的验证。银行、保险的报表科目结构差异很大
  （没有营业成本、有净息差和拨备），别名表在这些标的上的覆盖情况**尚未验证**；
- "可覆盖未接"的接口只验证了返回结构和样本值，未验证其在全市场标的上的
  稳定性和历史数据完整性。
